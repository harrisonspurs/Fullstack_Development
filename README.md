# Study Focus Tracker

A simple web app to track your study focus over time.

## How it works

1. Run the Study Focus Tracker on your computer while you study — it uses your webcam to see when you're actually focused
2. When you're done, it saves your session data as a JSON file
3. Go to **studentfocus.me** and paste your data to import it
4. See your stats and how focused you've been

## Use the site

Go to **https://studentfocus.me** and follow the guide there. Everything is explained on the site
